# UI-спека: сервис онлайн-записи на встречи (аналог Calendly)

**Задача:** сгенерировать полный интерфейс веб-приложения — кабинет владельца календаря и публичные страницы бронирования. Все экраны, компоненты и их состояния (default / hover / focus / active / disabled / loading / empty / error). Язык интерфейса — русский. Рабочее название-заглушка — **Slotix** (легко заменить).

**Продукт в одном абзаце:** владелец (консультант, преподаватель, эксперт) создаёт «форматы встреч» (тип события: длительность, расписание, локация, цена), получает публичную ссылку вида `slotix.ru/username/format` и делится ею. Клиент без регистрации выбирает свободный слот, оставляет имя и почту, бронирует. Система создаёт видеовстречу (Google Meet / Zoom / Телемост), событие в календаре и шлёт письма обеим сторонам. Владелец управляет бронями: подтверждает, отменяет, переносит.

---

## 1. UX-принципы (применять на каждом экране)

1. **Клиент бронирует за ≤ 30 секунд и ≤ 3 клика** — публичная страница важнее кабинета, на ней ноль лишних элементов.
2. **Автосохранение вместо кнопки «Сохранить»** — редактор формата сохраняет изменения сам; статус сохранения всегда виден.
3. **Ничего не теряется молча** — деструктивные действия (отмена встречи, удаление формата) требуют подтверждения с объяснением последствий; после действия — toast с итогом.
4. **Состояние системы всегда видно** — интеграция отвалилась, письмо не ушло, ссылка на видео не создалась → заметный, но не панический индикатор + понятное действие «как починить».
5. **Пустые состояния продают следующий шаг** — каждый пустой экран объясняет, что это, зачем и содержит одну главную кнопку.
6. **Время — всегда с таймзоной.** Везде, где показано время, рядом подпись таймзоны; на публичной странице — переключатель таймзоны клиента.
7. **Клавиатурная навигация и видимый focus-state** на всех интерактивных элементах.

## 2. Дизайн-система

Ниже — базовые токены как отправная точка. Можно уточнять оттенки и детали, но соблюдать: один акцентный цвет, спокойные нейтральные тона, «рабочий инструмент, а не лендинг». Не использовать фиолетово-градиентные AI-шаблоны.

### Палитра (light-тема — основная; dark-тема желательна)
- **Акцент:** глубокий тил `#0E8C7F` (hover `#0A6B61`, светлая подложка `#E2F1EE`)
- **Фон приложения:** `#F6F8F9`; **поверхности/карточки:** `#FFFFFF`
- **Текст:** основной `#1A2733`, вторичный `#5C6E7D`, линии/бордеры `#DAE2E8`
- **Семантика (не смешивать с акцентом):** успех `#15803D`, предупреждение `#B45309`, ошибка `#B91C1C`, инфо `#1D4ED8`
- **Цвета форматов встреч (палитра выбора из 10):** лаванда, серо-синий, горчичный, кирпичный, стальной синий, голубой, тил, песочный, тёмно-синий, фиолетовый — приглушённые, совместимые между собой; используются как полоса на карточке формата и метка в списках встреч.

### Типографика
- Один гротеск (например, Inter/Manrope/системный) — вес 600–650 для заголовков, 400–450 для текста.
- Шкала: 28/22/17/15/13/11. Цифры в таблицах и времени — `tabular-nums`.

### Сетка и формы
- Spacing по шкале 4: 4/8/12/16/24/32/48. Радиусы: инпуты и кнопки 8, карточки 12, модалки 16.
- Тени лёгкие, двухслойные; никаких жёстких чёрных теней.
- Иконки: линейные, 20px, единый набор (Lucide-стиль).

### Базовые компоненты (нужны все состояния)
| Компонент | Состояния и заметки |
|---|---|
| Кнопки: primary / secondary / ghost / destructive / icon-button | default, hover, focus, active, disabled, loading (спиннер вместо текста, ширина не прыгает) |
| Поля: text, textarea, select, combobox с поиском, время, дата | placeholder, filled, focus, error (текст ошибки снизу), disabled, с подсказкой «?» (tooltip) |
| Toggle, checkbox, radio, segmented control | вкл/выкл, disabled, с описанием |
| Chips/теги выбора (длительности, цвета) | selected / unselected / hover, custom-значение |
| Карточка, разделитель-аккордеон секций | collapsed/expanded, стрелка-индикатор |
| Toast (успех/ошибка, с кнопкой «Отменить действие» где уместно), Banner (предупреждение в разделе), Inline-alert | автоскрытие 5с у success, ошибки — до закрытия |
| Модалка подтверждения, Drawer (правая панель деталей) | с фокус-ловушкой, Esc закрывает |
| Таблица/список, пагинация, фильтры-дропдауны | загрузка-skeleton, пустой результат фильтра |
| Skeleton-блоки для всех списков и календаря | shimmer, повторяют геометрию контента |
| Avatar (фото/инициалы), бейдж тарифа, статус-бейджи броней | Подтверждена (зел.), Ждёт подтверждения (янтарный), Ждёт оплаты (серый), Отменена (красный контур), Перенесена (серый) |
| Tooltip, Popover, Dropdown-меню (⋯) | задержка 300мс, стрелочка |
| «Скопировать ссылку» | иконка → клик → галочка + toast «Ссылка скопирована» |

## 3. Информационная архитектура

**Кабинет (после логина):** сайдбар слева 240px, сверху лого + бейдж тарифа «Стандарт», снизу «Выйти» и переключатель языка RU/EN.
Пункты: Форматы встреч · Календари · Интеграции · Все встречи · Оплата · (Настройки профиля — через клик по аватару внизу сайдбара).
На мобильных сайдбар превращается в нижнюю навигацию из 4 пунктов + «Ещё».

**Публичная зона (без логина):** страница профиля `/username` → страница формата с выбором слота → форма → экран «Забронировано»; отдельные страницы отмены и переноса по ссылке из письма; страницы ошибок.

## 4. Экраны кабинета

### 4.1 Онбординг (после первого входа)
Одна страница-чеклист «Добро пожаловать!» с двумя шагами-карточками:
1. **«Расскажите о себе и выберите адрес страницы»** — разворачивается в форму: фото (загрузка с превью), имя, короткое описание, поле slug с живой проверкой уникальности (`slotix.ru/ + slug`, ниже статус: ✓ свободен / ✗ занят + предложения), таймзона (combobox с автоопределением, подпись «Определили автоматически — проверьте»).
2. **«Подключите аккаунт Google»** — кнопка «Войти с помощью Google» + пояснение «Нужно для синхронизации календаря и создания ссылок Google Meet». После подключения карточка сменяется на ✓ с именем аккаунта.
Внизу — primary «Сохранить и продолжить» (disabled, пока шаг 1 не заполнен; Google можно пропустить — ссылка «Настрою позже», с мягким предупреждением).
Состояния: ошибка занятого slug, ошибка OAuth (баннер «Не удалось подключить — попробовать ещё раз»).

### 4.2 Форматы встреч (главная кабинета)
- Заголовок «Форматы встреч», справа: сортировка, переключатель вид «сетка/список», primary «Добавить формат».
- Сверху **карточка профиля**: аватар, имя, публичная ссылка `slotix.ru/username`, кнопки «Скопировать ссылку» и «Открыть страницу» (external-иконка).
- **Карточка формата:** цветная полоса сверху (цвет формата), название (2 строки max), длительность, приватные бейджи: «Черновик» (если не опубликован), «₽ 3 000» (если платный), иконка видеопровайдера. Низ карточки: «Скопировать ссылку» (disabled у черновика, tooltip «Сначала опубликуйте»). Справа сверху меню ⋯: Редактировать, Дублировать, Выключить приём записей (toggle), Удалить (красный, с модалкой «Будущие встречи останутся в силе. Удалить формат?»).
- Hover карточки — лёгкий подъём тени, вся карточка кликабельна → редактор.
- **Пустое состояние:** иллюстрация календаря, «Создайте первый формат встречи», текст «Формат — это тип события, на который к вам записываются: консультация 30 минут, урок 60 минут…», кнопка «Добавить формат».
- Loading: 3 skeleton-карточки.

### 4.3 Редактор формата (самый насыщенный экран)
Шапка: breadcrumb «Форматы встреч / Название», статус автосохранения справа: «Сохраняем…» (спиннер) → «✓ Сохранено» (зелёная пилюля, гаснет через 2с) → при ошибке «Не сохранилось — повторить» (красный, кликабельный). Для черновика вместо статуса — primary «Опубликовать»; после публикации — ссылка формата с копированием + toggle «Приём записей: вкл».

Контент — одна колонка ~720px, секции-аккордеоны (первая раскрыта):

**Секция «Основная информация»**
- Выбор типа — 3 selectable-карточки в ряд: «Один на один» (Консультация, встреча, урок 1:1), «Групповая запись» (вебинар/урок с лимитом мест — при выборе появляется поле «Количество мест», stepper 2–100), «Сколько угодно участников». Выбранная — акцентная рамка + иконка.
- Палитра из 10 цветных квадратов, выбранный — с галочкой.
- «Название» (текст, подсказка «Так событие будет отображаться у клиента»), счётчик 60 симв.
- «Локация» — кнопка-поле «Нажмите, чтобы выбрать локацию» → popover со списком: Google Meet, Zoom, Яндекс Телемост, Своя ссылка (поле URL), Телефонный звонок (поле «кто кому звонит»), Адрес офлайн (текст). Можно добавить несколько — тогда клиент выберет при бронировании; выбранные показываются chip'ами с иконками провайдеров и крестиком. Если провайдер не подключён — chip с янтарной точкой и tooltip «Подключите Zoom в Интеграциях», ссылка.
- «Описание или инструкции» (textarea, markdown-lite: жирный, списки, ссылки).

**Секция «Сколько длится и когда доступно»**
- «Длительность»: chips 15 / 30 / 45 / 60 / 90 мин / 2 ч / 150 мин / 3 ч + chip «Своя…» (инпут минут).
- «Открытые дни»: строка «Для записи открыты следующие 60 дней» + ссылка «Изменить» → popover: radio «Скользящее окно N дней» (stepper) / «Диапазон дат» (два date-picker) / «Бессрочно».
- «Расписание» — недельная сетка 7 карточек-дней (пн–вс): в карточке дата, день недели, интервалы «10:00 — 17:00» (клик → редактирование, можно несколько интервалов в день, «+ интервал»), пустой день — серый «Недоступно». У каждого дня иконка повтора: «Применить ко всем понедельникам» и т.п. Стрелки ← → навигации по неделям, заголовок «13 июля — 19 июля 2026». Изменение конкретной даты (переопределение) помечается точкой «изменено вручную» с опцией «Вернуть по шаблону».

**Секция «Продвинутые настройки расписания»** (свёрнута, в заголовке — резюме «шаг слота 30 минут»)
- «Шаг слота»: select 10/15/20/30/60 мин, подсказка «С каким интервалом показывать время начала».
- «Буфер до встречи» и «Буфер после»: select 0/5/10/15/30 мин.
- «Минимальное время до брони»: select (например «за 2 часа»), подсказка «Нельзя записаться позже, чем за N до начала».
- «Лимит встреч в день»: stepper, off по умолчанию.
- Toggle «Подтверждать записи вручную» + описание «Клиент получит подтверждение только после вашего одобрения».

**Секция «Стоимость и способ оплаты»** (в заголовке — резюме «Бесплатно»)
- Toggle «Платная встреча» → поле суммы (₽), select провайдера (ЮKassa), текст «Деньги поступают напрямую на ваш счёт ЮKassa». Если платёжка не подключена — inline-alert с кнопкой «Подключить в Интеграциях».

Справа от колонки (на ≥1280px) — **липкое живое превью** публичной карточки формата (как увидит клиент): обновляется при вводе. На меньших ширинах — кнопка «Предпросмотр» в шапке (открывает модалку).

### 4.4 Календари
- Карточка подключённого Google-аккаунта: аватар/email, статус ✓ «Подключён» или ⚠ «Требуется переподключение» (красноватый бейдж + кнопка «Переподключить»).
- Блок «Куда записывать встречи»: radio-список календарей аккаунта (один выбран).
- Блок «Где проверять занятость»: чекбокс-список календарей («Слоты, пересекающиеся с событиями этих календарей, будут скрыты»).
- Кнопка «+ Подключить ещё аккаунт». Пустое состояние: объяснение двух функций календаря + кнопка подключения.

### 4.5 Интеграции
Сетка карточек провайдеров: Google Meet (через Google Calendar), Zoom, Яндекс Телемост, ЮKassa. У карточки: лого, название, короткое описание, статус: «Подключено» (✓ + email аккаунта, меню ⋯ → Отключить) / кнопка «Подключить» / ⚠ «Ошибка — переподключить». Отключение — модалка с последствиями («Форматы с Zoom-локацией переключатся на…»).

### 4.6 Все встречи
- Табы-фильтры: **Предстоящие** (по умолчанию) · Требуют действия (с красным счётчиком) · Прошедшие · Отменённые. Поиск по имени/почте клиента, фильтр по формату (multi-select), по диапазону дат.
- Список, сгруппированный по дням («Сегодня», «Завтра», «Пятница, 19 июля»): строка встречи = цветная точка формата, время «14:00 — 14:45», название формата, имя клиента, статус-бейдж, иконка видео (клик — открыть ссылку), меню ⋯.
- Клик по строке → **drawer справа** с деталями: клиент (имя, email, комментарий/ответы), время в двух таймзонах (владельца и клиента), локация со ссылкой, статус оплаты, история (создана, перенесена с…), действия: «Подтвердить» / «Отклонить» (для pending, primary/secondary), «Перенести», «Отменить встречу» (destructive, модалка с полем «Причина (увидит клиент)»), «Написать клиенту» (mailto).
- Требующие действия (pending) — строка с янтарной левой рамкой и кнопками Подтвердить/Отклонить прямо в строке.
- Пустые состояния для каждого таба (у «Предстоящих»: «Пока пусто. Поделитесь ссылкой — здесь появятся брони» + кнопка «Скопировать ссылку»).

### 4.7 Оплата (тариф)
Текущий тариф «Стандарт» карточкой, список включённого, сравнение тарифов (2–3 колонки, одна выделена «Рекомендуем»), история платежей таблицей. Для беты допустим упрощённый вид «Вы на раннем доступе — всё бесплатно».

### 4.8 Настройки профиля
Форма: фото, имя, описание, slug (с той же проверкой), таймзона, язык писем. Отдельный блок «Опасная зона»: удалить аккаунт (destructive, двойное подтверждение).

## 5. Публичные страницы (максимальный приоритет по качеству)

Общее: чистый светлый фон, максимум 640–960px, никакой навигации кабинета; внизу мелкое «Работает на Slotix». Обязательно идеальная мобильная версия — большинство клиентов придут с телефона по ссылке из мессенджера.

### 5.1 Профиль `/username`
Аватар, имя, описание; список карточек опубликованных форматов (цветная полоса, название, длительность, цена если платно, стрелка). Клик → страница формата.

### 5.2 Бронирование `/username/format` — ключевой флоу
Desktop — двухпанельная карточка:
- **Слева (инфо):** аватар+имя владельца, название формата, мета-строки с иконками: ⏱ 45 минут, 📍 Google Meet (или «Выбор из: Meet / Zoom» если опций несколько), ₽ цена если платно, описание.
- **Справа (шаги):**
  **Шаг 1 — дата:** календарь месяца; дни со свободными слотами — акцентные кружки, без слотов — серые disabled; сегодня — контур. Стрелки месяца (назад disabled в прошлое). Под календарём — селектор таймзоны: «🌐 Москва (GMT+3)» combobox с поиском, дефолт — автоопределение.
  **Шаг 2 — время:** при выборе дня справа/снизу выезжает колонка времён: кнопки-слоты «10:00», «10:30»… (вертикальный список, скролл). Клик по слоту → кнопка разъезжается на «10:00» + primary «Далее» (паттерн подтверждения Calendly).
  **Шаг 3 — форма:** выбранные дата-время сверху с кнопкой «← Изменить», поля: Имя*, Email*, «Комментарий» (textarea, optional), выбор локации (radio-карточки, если опций несколько). Primary — «Забронировать» (или «Перейти к оплате • 3 000 ₽»). Ниже мелко: «Подтверждение придёт на почту».
- Mobile: шаги последовательные экраны с прогрессом и кнопкой назад.
- Состояния: загрузка слотов — skeleton-кружки в календаре и skeleton-кнопки времени; **слот заняли во время оформления** — inline-alert «Это время только что заняли. Выберите другое» + автообновление списка; месяц без слотов — «В этом месяце всё занято» + кнопка «Следующий месяц»; оплата не прошла — alert с повтором.

### 5.3 Экран «Встреча забронирована»
Большая зелёная галочка, «Вы записаны!» (или «Запрос отправлен» + янтарные часы, если требуется подтверждение владельцем: текст «NAME подтвердит встречу, мы напишем вам на почту»). Карточка деталей: формат, дата и время в таймзоне клиента, длительность, локация (кнопка «Ссылка на встречу» если уже есть), владелец. Кнопки: «Добавить в Google Календарь», «Скачать .ics», ссылки «Перенести» и «Отменить запись».

### 5.4 Отмена и перенос (по ссылке из письма)
- Отмена: карточка встречи, поле «Причина (необязательно)», destructive «Отменить встречу», после — состояние «Встреча отменена» с предложением «Записаться заново».
- Перенос: та же сетка слотов (5.2, шаги 1–2), сверху бейдж «Перенос встречи с 18 июля, 14:00»; подтверждение «Перенести на …».
- Ссылка устарела/встреча уже отменена — понятная страница-заглушка.

### 5.5 Служебные страницы
«Запись закрыта» (формат выключен/удалён): аватар владельца, «NAME сейчас не принимает записи по этой ссылке», кнопка на профиль. 404 — в стиле продукта.

## 6. Письма (шаблоны, 600px, простой HTML-стиль в тон продукта)

## 7. Адаптивность и прочее
- Breakpoints: ≥1280 (сайдбар + превью), 768–1279 (сайдбар сжимается в иконки), <768 (нижняя навигация; редактор — одна колонка; таблицы становятся карточками).
- Тёмная тема приветствуется для кабинета; публичные страницы могут остаться светлыми.
- Все списки: skeleton при загрузке, пустое состояние, состояние ошибки сети («Не удалось загрузить — Повторить»).
- Тон текстов: дружелюбный, без канцелярита, действия называются результатом («Опубликовать», «Забронировать», toast «Опубликовано»).
