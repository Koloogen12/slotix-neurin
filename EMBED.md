# Встраивание записи Slotix в чужой сайт

Виджет открывается модальным окном поверх страницы — посетитель не уходит на slotix.neurin.tech.
Если встраивание заблокировано (CSP или расширение в браузере), скрипт сам открывает запись в
новой вкладке, а не оставляет пустое окно.

## Быстрый старт

```html
<script src="https://slotix.neurin.tech/embed.js" defer></script>

<button data-slotix="https://slotix.neurin.tech/<slug>/<formatId>"
        data-slotix-cta="hero">
  Разобрать гипотезу
</button>
```

Ссылка в `data-slotix` — обычная ссылка на формат, та же, что вы поставили бы в `href`.
Скрипт сам превращает её в `/embed/<slug>/<formatId>`: только этот префикс отдаётся без шапки
сайта и только его разрешено помещать в iframe.

Элемент может быть любым — `<button>`, `<a>`, `<div>`. Обработчик делегированный, поэтому кнопки,
появившиеся после загрузки скрипта (React, ленивая секция), тоже работают.

**Держите `<a href>` рабочим.** Если писать `<a href="https://slotix.neurin.tech/<slug>/<formatId>"
data-slotix="...">`, то при отключённом JS ссылка останется кликабельной и уведёт на страницу
записи — деградация вместо мёртвой кнопки.

## Атрибуты

| Атрибут | Зачем |
|---|---|
| `data-slotix` | Ссылка на формат. Обязательный. |
| `data-slotix-cta` | Метка кнопки — попадёт в события аналитики и в ссылку как `?cta=`. |
| `data-slotix-name` | Предзаполнить имя. |
| `data-slotix-email` | Предзаполнить почту. |
| `data-slotix-comment` | Предзаполнить комментарий — сюда кладут сегмент или название формата. |
| `data-slotix-title` | Заголовок модального окна для скринридера. |

UTM-метки подставлять не нужно: скрипт сам переносит `utm_source/medium/campaign/content/term`
с адреса страницы, на которой стоит кнопка, в ссылку виджета. Метка, уже прописанная в
`data-slotix` вручную, имеет приоритет.

## Программный вызов

```js
Slotix.open("https://slotix.neurin.tech/<slug>/<formatId>", {
  cta: "final",
  comment: "Формат: предпродажи",
});
Slotix.close();
```

Встроить календарь прямо в страницу, без модалки — окно само растёт под содержимое:

```html
<div data-slotix-inline-url="https://slotix.neurin.tech/<slug>/<formatId>"></div>
```

```js
Slotix.inline("#booking", "https://slotix.neurin.tech/<slug>/<formatId>", { minHeight: 700 });
```

## События

Каждое приходит тремя путями — DOM-событием на `window`, пушем в `dataLayer` (если он есть) и
колбэком. Берите любой.

| Событие | Когда | `detail` |
|---|---|---|
| `slotix:open` | окно открылось | `url`, `cta` |
| `slotix:ready` | виджет загрузился внутри окна | — |
| `slotix:booked` | запись создана | `formatId`, `startAt`, `cta` |
| `slotix:close` | окно закрылось | — |
| `slotix:fallback` | встроить не удалось, открыли вкладку | `url` |

```js
window.addEventListener("slotix:booked", function (e) {
  ym(XXXXXX, "reachGoal", "booking_created", { cta: e.detail.cta });
});

// либо
Slotix.onBooked = function (detail) { /* ... */ };
```

`slotix:booked` срабатывает в момент создания записи. Для платного формата это происходит до
оплаты — виджет сразу уходит на страницу провайдера, и другого момента сообщить хосту уже не
будет. Оплачено или нет — это отдельное состояние, оно придёт вебхуком, когда он появится.

## Воронка из спеки лендинга

| Шаг | Чем меряется |
|---|---|
| 2 · Клик по кнопке записи | `slotix:open` (в `detail.cta` — какая кнопка) |
| 3 · Открыта запись | `slotix:ready` |
| 4 · Запись завершена | `slotix:booked` |

Шаги 2–4 закрываются аналитикой на стороне сайта, без интеграции с Slotix. Шаг 4 в CRM — это
вебхук, его пока нет.

## Кто может встраивать

По умолчанию `frame-ancestors *` — виджет ставится на любой сайт, иначе на каждого клиента
пришлось бы выкатывать деплой. Страницы под `/embed/` публичные и не содержат действий от имени
залогиненного пользователя, поэтому обычный риск кликджекинга к ним не применим.

Ограничить список доменов — переменная окружения фронтенда:

```
EMBED_FRAME_ANCESTORS="https://studio.example https://www.studio.example"
```

Читается на сборке (`next.config.ts`), так что после изменения нужна пересборка образа.

## Чего виджет пока не умеет

Спека лендинга просит ещё четыре вещи, которых в Slotix нет:

1. **Свои вопросы в записи** — сейчас только имя, почта и свободный комментарий. Четыре
   обязательных вопроса из спеки (два выбора, длинный текст, канал связи) требуют модели
   вопросов у формата.
2. **Вебхук при записи** — для CRM или таблицы.
3. **Напоминания за 24 часа и добивка после неявки** — есть только письмо сразу и напоминание
   за час.
4. **Сообщения клиенту в Telegram** — у записи нет telegram-контакта клиента, уходит только
   почта. Telegram получает владелец.

До появления пункта 1 ответы на вопросы 1–2 из спеки можно передавать предзаполненным
комментарием: `data-slotix-comment="Фаундер · продукт есть, выручки нет"`.
