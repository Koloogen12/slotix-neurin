# Запись Slotix на лендинге студии

Инструкция для того, кто пишет сайт. Виджет открывается модальным окном поверх страницы,
посетитель не уходит на slotix.neurin.tech. Подробности API — в `EMBED.md`, здесь только то,
что нужно на лендинге.

## 1. Подключить скрипт

Один тег в `<head>` или перед `</body>`:

```html
<script src="https://slotix.neurin.tech/embed.js" defer></script>
```

Зависимостей нет, 14 КБ, ничего не грузит до первого клика.

## 2. Кнопки

Форматы уже заведены в аккаунте `kochnev`, вопросы настроены:

| Формат | Ссылка |
|---|---|
| Разбор гипотезы, 30 мин | `https://slotix.neurin.tech/kochnev/0cba0e23-be53-400b-ac25-0e43b80c42be` |
| Встреча с командой, 45 мин | `https://slotix.neurin.tech/kochnev/e6a116fe-849e-4873-a850-7877a87c2a90` |

Разметка кнопки:

```html
<a href="https://slotix.neurin.tech/kochnev/0cba0e23-be53-400b-ac25-0e43b80c42be"
   data-slotix="https://slotix.neurin.tech/kochnev/0cba0e23-be53-400b-ac25-0e43b80c42be"
   data-slotix-cta="hero">
  Разобрать гипотезу
</a>
```

**`href` оставляйте рабочим.** Без JS ссылка уведёт на страницу записи, а не превратится в
мёртвую кнопку. Скрипт перехватывает клик и отменяет переход сам.

Элемент может быть любым — `<a>`, `<button>`, `<div>`. Обработчик делегированный, так что
кнопки, отрисованные позже (React, ленивая секция), тоже работают.

### Какая кнопка куда — по таблице «Кнопки и воронка» из спеки

| Где | `data-slotix` | `data-slotix-cta` | Предзаполнение |
|---|---|---|---|
| Шапка | Разбор | `header` | — |
| Первый экран | Разбор | `hero` | — |
| Блок 03, фаундер | Разбор | `seg-founder` | `q-role="Фаундер"` `q-stage="Продукт есть, выручки нет"` |
| Блок 03, растущая | Разбор | `seg-growth` | `q-role="Растущая компания"` `q-stage="Выручка есть, рост встал"` |
| Блок 03, корпорация | Разбор | `seg-corp` | `q-role="Корпорация"` `q-stage="Корпоративный пилот или новое направление"` |
| Блок 04, после «С чего начать» | Разбор | `method` | — |
| Блок 09, «Подожду» | Разбор | `alternatives` | — |
| Блок 11, вход | Разбор | `formats-entry` | — |
| Блок 11, платные форматы | Разбор | `format-<латиница>` | `comment="Формат: <название>"` |
| Блок 11, корпоративное | Встреча с командой | `corp` | `q-role="Корпорация"` |
| Финал | Разбор | `final` | — |
| Мобильная закреплённая | Разбор | `sticky` | — |

Предзаполнение пишется как `data-slotix-q-<ключ>="значение"` и `data-slotix-comment="..."`.
Посетитель видит выбранный вариант отмеченным и может его поменять.

### Вопросы в записи — ключи и точные варианты

Одинаковые у обоих форматов, все обязательные:

| Ключ | Вопрос | Тип |
|---|---|---|
| `role` | Кто вы | выбор |
| `stage` | Где вы сейчас | выбор |
| `hypothesis` | Какую гипотезу хотите проверить или что не работает | текст, от 60 символов |
| `contact` | Как удобнее связаться — Telegram, телефон или почта | строка |

Варианты — **дословно**, сервер отклонит значение, не совпавшее символ в символ:

- `role`: `Фаундер` · `Растущая компания` · `Корпорация`
- `stage`: `Есть гипотеза, продукта нет` · `Продукт есть, выручки нет` ·
  `Выручка есть, рост встал` · `Корпоративный пилот или новое направление`

`hypothesis` и `contact` с лендинга не предзаполняются — их пишет сам человек.

UTM подставлять не нужно: скрипт сам переносит `utm_source/medium/campaign/content/term` с
адреса страницы в виджет.

## 3. Аналитика

Три события на `window`, плюс пуш в `dataLayer`, если он есть. Они закрывают шаги 2–4 воронки
из спеки без всякой интеграции с нашим API:

```js
window.addEventListener("slotix:open",   (e) => { /* шаг 2: клик, e.detail.cta */ });
window.addEventListener("slotix:ready",  ()  => { /* шаг 3: форма открылась */ });
window.addEventListener("slotix:booked", (e) => { /* шаг 4: запись создана */ });
```

Пример для Метрики:

```js
window.addEventListener("slotix:booked", (e) => {
  ym(XXXXXX, "reachGoal", "booking_created", { cta: e.detail.cta });
});
```

Ещё два события — `slotix:close` и `slotix:fallback` (встроить не удалось, открыли вкладку).

## 4. Мобильная закреплённая кнопка

Та же разметка, метка `sticky`. На экранах ≤640px модалка сама раскрывается во весь экран.

## 5. Что проверить перед публикацией

- [ ] Кнопка открывает окно, а не уводит на другой домен
- [ ] С выключенным JS ссылка всё ещё ведёт на страницу записи
- [ ] `?utm_source=test` на лендинге долетает до записи (видно в кабинете Slotix → Источники)
- [ ] Предзаполненный ответ подставился в форму
- [ ] После записи сработало `slotix:booked`
- [ ] На мобильном окно занимает весь экран и закрывается крестиком

Локальная проверка: `docs/embed-demo.html` в этом репозитории — подставьте свои slug и formatId
и откройте по http (например `npx serve docs`), не через `file://`.

## Чего на нашей стороне ещё нет

- **Свой текст экрана «спасибо»** после записи — он общий для всех форматов. Текст из спеки
  («Встреча в календаре. Чтобы за 30 минут успеть больше…») пока показать нечем; если он важен,
  скажите — сделаем настройку у формата.
- **Вопрос с несколькими вариантами ответа** — только выбор одного из списка.

## Что уже настроено в кабинете

Оба формата опубликованы, бесплатные, видеосвязь — Google Meet, расписание общее для аккаунта.
Вопросы меняются на странице формата в кабинете (раздел «Вопросы при записи»); **менять
ключи и формулировки вариантов нельзя без правки разметки лендинга** — предзаполнение
перестанет совпадать.
