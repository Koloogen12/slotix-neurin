# Handoff: Slotix — сервис онлайн-записи на встречи

## Overview
Slotix — сервис планирования встреч, консультаций и занятий (аналог Calendly/Qlick).
Специалист настраивает форматы встреч и расписание, получает публичную ссылку;
клиент открывает ссылку, выбирает свободный слот и бронирует встречу, указав только email.
Пакет покрывает весь путь: маркетинговый лендинг → регистрация (по email) → онбординг →
личный кабинет → публичная страница брони → письма.

## About the Design Files
Файлы в этом пакете — **дизайн-референсы, созданные в HTML** (прототипы, показывающие
внешний вид и поведение), а не продакшн-код для прямого копирования. Задача — **воссоздать
эти макеты в вашем кодовом окружении** (React/Vue/и т.п.), используя устоявшиеся в проекте
паттерны и библиотеки. Если окружения ещё нет — выберите подходящий фреймворк и реализуйте
макеты в нём.

Технически каждый файл — «Design Component» (`*.dc.html`): шаблон + класс логики,
исполняемые рантаймом `support.js`. Это удобно для просмотра, но в проде воссоздавайте
компоненты нативно. Стили заданы инлайн намеренно (особенность прототипа) — при переносе
вынесите их в дизайн-токены / систему стилей (см. раздел Design Tokens).

## Fidelity
**High-fidelity (hifi).** Финальные цвета, типографика, отступы и интерактив.
Воссоздавайте UI попиксельно, подставляя компоненты вашей системы.
Исключение — раздел «Направления - Бронирование.dc.html», это исследование вариантов (lofi/сравнение).

## Design language
Эстетика «aurora glass»: светлый градиентный фон-аврора, стеклянные карточки
(полупрозрачный белый + `backdrop-filter: blur`), мягкие тени, крупная типографика Golos Text.
**Важно:** стекло (`backdrop-filter`) применимо в вебе-приложении, но НЕ в письмах —
письма используют плотные фоны и inline-стили (см. «Slotix - Письма»).

### Стеклянная карточка (приложение)
`background: rgba(255,255,255,.60)` · `backdrop-filter: blur(30px) saturate(1.4)` ·
`border: 1px solid rgba(255,255,255,.55)` · `border-radius: 24–32px` ·
`box-shadow: 0 20px 50px rgba(20,40,70,.08–.12)`

### Карточка письма (email-safe)
`background:#fff` · `border-radius:20px` · `box-shadow:0 20px 50px rgba(20,40,70,.14)` ·
шапка светлая с логотипом + верхняя градиентная полоса 4px.

### Типографика
- Семейство: **Golos Text** (400/500/600/700/800), фолбэк `system-ui, sans-serif`.
- H1 (герой): 800, `clamp(34px,4.6vw,56px)`, `line-height:1.06`, `letter-spacing:-.02em`.
- H2 секций: 800, `clamp(28px,3.4vw,42px)`.
- Заголовок карточки: 700, 22–26px. Тело: 400–500, 14–16px, `line-height:1.5–1.55`.
- Мелкие подписи/статусы: 600–700, 12–13px.

### Радиусы / тени / отступы
- Радиусы: кнопки/поля 12–14px, чипы/пилюли 100px, карточки 18–32px, аватар 50%.
- Кнопка-акцент тень: `0 8–12px 22–28px rgba(80,148,240,.3–.38)`.
- Секции лендинга: вертикальный ритм `clamp(40px,6vw,80–96px)`, контейнер `max-width:1200px`.

### Адаптив
Без медиазапросов, через `flex-wrap` + `clamp()` + `grid auto-fit minmax(260px,1fr)`.
Где нужна логика (навигация лендинга, раскладка страницы брони) — брейкпоинт по `window.innerWidth`:
лендинг скрывает якорные пункты меню `< 720px`; страница брони переключается на 1 колонку `< 1080px`.

## Screens / Views

### 1. Лендинг — `Slotix - Лендинг.dc.html`
- **Назначение:** привлечение и регистрация посетителей (email → онбординг).
- **Секции:** прилипающая стеклянная навигация (лого, Возможности/Интеграции/Тарифы, Вход, Регистрация);
  герой (заголовок + захват email + кнопка «Начать бесплатно», справа — мокап переписки с
  плавающей карточкой «С Slotix — 1 клик», либо превью брони — переключается пропом `heroVisual`);
  3 карточки «как это работает»; превью продукта с мини-календарём; интеграции (Zoom, Google Meet,
  Телемост / Google Календарь / оплата); финальный CTA-баннер (мятно-голубой градиент); футер.
- **Проп-твики:** `heroVisual` (`chat`|`booking`), `showFloatingCard` (bool).
- **Навигация:** «Начать бесплатно»/«Регистрация» → Онбординг; «Вход» → Кабинет.

### 2. Онбординг — `Slotix - Онбординг.dc.html`
- **Назначение:** первичная настройка после регистрации.
- Шаг 1: имя, описание, аватар, выбор адреса `slotix.ru/{slug}` (с проверкой доступности), часовой пояс.
- Шаг 2: подключение Google-аккаунта (состояние вкл/выкл).

### 3. Страница брони (десктоп) — `Slotix - Страница брони.dc.html`
- **Назначение:** публичная запись клиента. Шаги: выбор даты/времени → форма (имя/email/коммент) → оплата → «Вы записаны».
- Двухколоночная стеклянная карточка: слева инфо о формате (эксперт, длительность, канал, цена),
  справа календарь + список слотов; адаптив в 1 колонку `< 1080px`.

### 4. Мобильная бронь — `Slotix - Мобильная бронь.dc.html`
- Мобильная версия страницы брони.

### 5. Личный кабинет — `Slotix - Кабинет.dc.html` (+ секции)
- **Назначение:** рабочее место специалиста. Секции подключаются отдельными файлами:
  `MeetingsSection`, `CalendarsSection`, `IntegrationsSection`, `BillingSection`, `SettingsSection`, `FormatEditor`.
- `Slotix - Кабинет (Cal.com).dc.html` — альтернативный вариант оформления кабинета.

### 6. Публичные экраны — `Slotix - Публичные экраны.dc.html`
- Состояния публичной ссылки: профиль (список форматов), отмена, перенос, закрыто, 404.

### 7. Письма — `Slotix - Письма.dc.html`
Email-safe макеты, 8 типов (переключатель сверху):
1. **Вы записаны** — подтверждение клиенту (детали + «Подключиться», в календарь/перенести/отменить).
2. **Вход по ссылке** — passwordless: кнопка «Войти в Slotix» + 6-значный код, срок 15 мин (ключевое для email-регистрации).
3. **Запрос отправлен** — ожидание подтверждения владельцем.
4. **Владельцу: новая** — заявка на встречу с кнопками Подтвердить/Отклонить.
5. **Оплата** — чек: услуга, дата, способ, итого, «Скачать чек (PDF)».
6. **Перенос** — старое время зачёркнуто, новое выделено; Подтвердить/Выбрать другое.
7. **Отмена** — причина + «Записаться заново».
8. **Напоминание** — за 1 час до встречи.

### 8. Направления - Бронирование — `Направления - Бронирование.dc.html`
- Исследование вариантов (сравнение направлений), lofi. Использовать как справочное, не как финал.

## Interactions & Behavior
- Все интерактивные состояния — в классах логики (`class Component extends DCLogic`): смена шагов
  брони, выбор слота, переключение типов писем/публичных состояний — через `state` + `setState`.
- Анимации: пульсация точек «печатает» и лёгкий float плавающей карточки (`@keyframes` в лендинге);
  hover-состояния кнопок/ссылок через `style-hover`, фокус полей — `style-focus`.
- Навигация между экранами — обычными ссылками на соответствующие файлы (в проде — роуты).

## State Management
- Локальный UI-стейт на экран (текущий шаг брони, выбранный слот, активный таб письма/состояния,
  ширина окна для адаптива, флаги подключения Google).
- Данные (форматы, слоты, брони, платежи, интеграции) в проде тянутся с бэкенда — в прототипах захардкожены.
